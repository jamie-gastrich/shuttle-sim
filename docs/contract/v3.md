# Message contract v3

Version: 3

## MessageEnvelope

Nested as `Envelope` in every message

| Field | JSON type | C# type | Meaning | Required |
|---|---|---|---|---|
| `ContractVersion` | `int` | `int` | Version of the message contract the sender used; receivers use it to check compatibility | yes |
| `MessageType` | `string` | `string` | which kind of message (wire name) | yes |
| `MessageId` | `string` | `string` | fresh GUID per message | yes |
| `CorrelationId` | `string` | `string?` | null on a new message; on an ack, the originating command's MessageId | no |
| `SenderId` | `string` | `string` | fleet-manager or the shuttle id | yes |
| `SentAt` | `string, ISO 8601 UTC` | `DateTime` | UTC time when the sender created the message | yes |

| Message Type | Wire name | Topic kind segment |
|---|---|---|
| `MoveCommandMessage` | `moveCommand` | `command` |
| `CommandAckMessage` | `commandAck` | `ack` |
| `ShuttleStatusMessage` | `shuttleStatus` | `status` |

```json
{
    "ContractVersion": 3,
    "MessageType": "moveCommand",
    "MessageId": "96dfbc67-1293-4f39-afe3-e33cba4aea51",
    "CorrelationId": null,
    "SenderId": "fleet-manager",
    "SentAt": "2026-10-08T12:00:00Z"
}
```

## Alarm

Sent by a shuttle to the fleet manager?

| Field | JSON type | C# type | Meaning | Required |
|---|---|---|---|---|
| `ShuttleId` | `string` | `string` | which shuttle this is about | yes |
| `Severity` | `string` | `string` | how urgent: `info`, `warning`, or `critical` | yes |
| `Code` | `string` | `string` | which fault, as a short stable name: `lostCommunication`, `blockedPath`, or `palletNotDetected` | yes |
| `Detail` | `string` | `string?` | a human sentence, or nothing (`null`) | no |


```json
{
    "ShuttleId": "SH-02",
    "Severity": "critical",
    "Code": "lostCommunication",
    "Detail": null
}
```

## CommandAckMessage

Sent by a shuttle to the fleet manager.

| Field | JSON type | C# type | Meaning | Required |
|---|---|---|---|---|
| `Envelope` | `MessageEnvelope` | `MessageEnvelope` | Message metadata used to identify its version, kind, sender, and the command this acknowledgement answers | yes |
| `Accepted` | `bool` | `bool` | Whether the shuttle accepted the command and applied its requested effect | yes |
| `Reason` | `string` | `string?` | Explanation for why the command was rejected; null when accepted | no |


```json
{
    "Envelope": {
        "ContractVersion": 3,
        "MessageType": "commandAck",
        "MessageId": "99fa5909-5264-49e5-a5b4-e2c8621a9efa",
        "CorrelationId": "96dfbc67-1293-4f39-afe3-e33cba4aea51",
        "SenderId": "SH-01",
        "SentAt": "2026-10-08T12:00:00Z"
    },
    "Accepted": true,
    "Reason": null
}
```

## ShuttleStatusMessage

Sent by a shuttle to the fleet manager.

| Field | JSON type | C# type | Meaning | Required |
|---|---|---|---|---|
| `Envelope` | `MessageEnvelope` | `MessageEnvelope` | Message metadata used to identify its version, kind, and sender | yes |
| `Status` | `ShuttleStatus` | `ShuttleStatus` | Snapshot of the shuttle's current state, position, and any reported fault | yes |

```json
        "SenderId": "SH-01",
        "SentAt": "2026-10-08T12:00:00Z"
    },
    "Status": {
        "ShuttleId": "SH-01",
        "State": "idle",
        "Position": "A02-L04",
        "Timestamp": "2026-10-08T12:00:00Z",
        "FaultReason": null
    }
}
```

## ShuttleStatus

Sent by a shuttle to the fleet manager.

| Field | JSON type | C# type | Meaning | Required |
|---|---|---|---|---|
| `ShuttleId` | `string` | `string` | Which shuttle sent the report, e.g. SH-01 | yes |
| `State` | `string` | `string` | Where the shuttle's state machine is. One of: `idle`, `moving`, `loading`, `unloading`, `fault` (the states the spec names in M1) | yes |
| `Position` | `string` | `string` | The rack lane the shuttle is in, e.g. `A02-L04` | yes |
| `Timestamp` | `string, ISO 8601 UTC` | `DateTime` | When the report was made | yes |
| `FaultReason` | `string` | `string?` | What is wrong. Meaningful only when `State` is `fault`; otherwise `null` or absent, e.g. `blocked path`, `lost communication`, `pallet not detected` | no |


```json
{
    "ShuttleId": "SH-01",
    "State": "idle",
    "Position": "A02-L04",
    "Timestamp": "2026-10-08T12:00:00Z",
    "FaultReason": null
}
```

## Changing this contract

Changing a message in this file needs a decision record in `docs/decisions/` and a
version bump: the new shape gets a new page (`v4.md`) and `v3.md` stays, so a payload
written for version 1, 2, & 3 can still be read.
